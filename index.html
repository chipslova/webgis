💡 Panduan Warna Merah & Curah Hujan:
• Peta LST (Suhu): Merah = Permukaan daratan panas (34°C–40°C+ saat siang/kemarau). Lautan transparan.
• Tutupan Lahan (LULC): Merah = Lahan Terbangun / Perkotaan (Built-Up Area).
• Curah Hujan (CHIRPS/GPM): Biru-Hijau = Hujan ringan/sedang (5–20 mm), Kuning-Merah-Ungu = Hujan lebat/ekstrem (>30 mm/hari).

WebGIS Observasi Bumi Indonesia

Platform Pengamatan Bumi & Analisis Spasial Mandiri

ℹ️ Pernyataan Kemandirian Proyek & Sumber Data Aplikasi ini merupakan platform WebGIS independen yang dikembangkan oleh chipslova. Aplikasi mengakses endpoint publik OGC Web Map Service (WMS) BIG Piksel serta dataset geospasial terbuka (ESA Copernicus, USGS/NASA, OpenStreetMap). Bukan aplikasi resmi Badan Informasi Geospasial atau Geoscience Australia.
01
Eksplorasi

Sentinel-2 GeoMAD, Landsat 9, NDVI, NDWI, model bahaya banjir — via BIG Piksel OGC WMS.

02
Analisis

Suhu permukaan tanah MODIS LST, pulau panas perkotaan (UHI), elevasi DEM SRTM — studi kasus pemodelan spasial.

03
Interaksi

Pengukuran geodesik, impor GeoJSON, manajemen tumpukan lapisan, galeri peta dasar, ekspor peta.

🚀 PANDUAN MULAI CEPAT
1
Pilih Citra Satelit Buka tab Satelit, pilih produk (Sentinel-2, NDVI, dll.), lalu klik untuk mengaktifkan.
2
Kustomisasi Tampilan Peta Pada tab Lapisan — ganti peta dasar dan atur transparansi lapisan aktif.
3
Analisis & Pengukuran Gunakan Ukur untuk jarak/luas, atau Analisis untuk studi kasus termal dan profil elevasi.
4
Ekspor Hasil Klik Ekspor Peta untuk tangkapan gambar PNG bergeoreferensi, atau unduh dataset dari Analisis.

Aktivasi Real Google Earth Engine (GEE)

🛰️ Fitur Piksel Satelit Gratis Sudah Aktif!
WebGIS ini sekarang otomatis menjalankan Client-Side Pixel Sampling langsung dari citra satelit Sentinel-2 10m & data suhu Open-Meteo realtime. Kamu tidak wajib setup akun apapun untuk mendapatkan data riil!

Jika kamu ingin menghubungkan ke Cluster Superkomputer Google Earth Engine (MODIS & ESA WorldCover) secara 100% GRATIS tanpa diminta kartu kredit / billing, ikuti panduan pendaftaran jalur non-komersial berikut:

1
Daftar GEE Non-Komersial (Bebas Kartu Kredit)

Jangan mendaftar lewat GCP Console biasa agar tidak ditagih billing! Buka portal resmi non-komersial: code.earthengine.google.com/register ↗. Pilih "Unpaid / Noncommercial" ➔ "Academia & Research" atau "Personal / Hobby", lalu pilih "Create a new Google Cloud Project" di form tersebut (Gratis tanpa penagihan).

2
Buat Service Account

Setelah project terdaftar, buka menu APIs & Services ➔ Credentials di project tersebut, buat Service Account baru dengan role Earth Engine Resource User.

3
Unduh Kunci JSON & Tempel ke Vercel

Klik Service Account ➔ Keys ➔ Add Key (JSON). Salin seluruh isi file JSON tersebut ke Vercel Settings ➔ Environment Variables dengan nama:
GEE_SERVICE_ACCOUNT_KEY.

✨ 100% Bebas Biaya: Earth Engine untuk keperluan edukasi, riset, dan portofolio personal tidak dipungut biaya sepeserpun.
