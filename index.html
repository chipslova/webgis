💡Cara Menggunakan Analisis Suhu:

  1. Pilih Mode Waktu di bawah (☀️ Siang Hari untuk cek Panas Kota / 🌙 Malam Hari untuk pendinginan).
  2. Klik pada pulau atau kota di peta Indonesia untuk membaca nilai suhu akurat (°C).
  3. Bandingkan warna termal: Merah/Oranye = Panas Perkotaan (UHI), Hijau/Biru = Sejuk Hutan & Pegunungan.

Indonesia Earth Observation WebGIS

Independent Earth Observation & Spatial Analytics Platform

ℹ️ Project Independence & Data Provenance Disclaimer This application is an independent WebGIS platform developed by chipslova. It consumes public OGC Web Map Service (WMS) endpoints from BIG Piksel and open geospatial datasets (ESA Copernicus, USGS/NASA, OpenStreetMap). It is not an official application of Badan Informasi Geospasial or Geoscience Australia.
01
Exploration

Sentinel-2 GeoMAD, Landsat 9, NDVI, NDWI, flood hazard models — via BIG Piksel OGC WMS.

02
Analysis

MODIS land surface temperature, urban heat contrast, SRTM elevation — spatial modeling case studies.

03
Interaction

Geodesic measurement, GeoJSON import, layer stack management, basemap gallery, map export.

🚀 QUICK START GUIDE
1
Select Satellite Imagery Open the Satellite tab, select a product (Sentinel-2, NDVI, etc.), and click to activate.
2
Customize Map View In the Layers tab — switch basemaps and adjust layer transparency.
3
Analyze & Measure Use Measure for distance/area, or Analysis for thermal case studies.
4
Export Results Click Export Map for PNG image capture, or download datasets from Analysis.
⚙️ Data Pipeline Architecture (Client ↔ Backend)
Client: MapLibre GL JS (WebGL 2D & 3D Globe Projection)
↓
Protocols: OGC WMS 1.3.0 • PMTiles • GeoJSON • Turf.js Geodesics
↓
Backend: Open Data Cube (BIG Piksel) • Precomputed Datasets (MODIS/SRTM)
